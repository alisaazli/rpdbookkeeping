RPD HUB — BUILD 0.4.10 NOTES

Based on the supplied Build 0.4.9 package. This is a focused correction after iPhone verification showed that the previous print CSS fixed header overlapped report content and the Reports date controls still overflowed.

- Print output now uses a dedicated white A4 layout rather than inheriting the app's mobile card layout.
- Print document includes the exact official letterhead logo and only the approved company name, registration number, address and email.
- Each generated print page has its own letterhead. Transactions are grouped into explicit pages and transaction table headings repeat within each page.
- Increased specificity and applied border-box sizing to Reports date inputs and selects to prevent iOS intrinsic-width overflow beyond the Report Settings card.
- Preserved the PDF export implementation, app icon, official letterhead asset, localStorage key rpd_bookkeeping_v2, and existing resident/refund workflows.
